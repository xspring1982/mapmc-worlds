# Washington, United States as a Minecraft Bedrock World

This is a Minecraft Bedrock world based on Washington, United States.

It was generated with [MapMC](https://mapmc.app) from real-world map data. It is a playable starting point for city-building, exploration, and editing rather than a perfect hand-built replica.

- Edition: Bedrock
- Package: `mapmc-world-bedrock.mcworld`
- Package size: 1.03 MB

## Install

1. Download `mapmc-world-bedrock.mcworld`.
2. Open the `.mcworld` file with Minecraft Bedrock Edition.
3. Import the world, then open it from your world list.
